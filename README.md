# UI Автотесты для сервиса аренды самокатов

## Описание проекта
Данный проект представляет собой набор автотестов для проверки функциональности веб-приложения сервиса аренды самокатов.
Тесты написаны с использованием `pytest`, `selenium` и `allure`.

## Структура проекта
```
project_root/
│── pages/               # Классы для работы со страницами
│   ├── base_page.py     # Базовый класс для всех страниц
│   ├── main_page.py     # Главная страница
│   ├── order_page.py    # Страница оформления заказа
│   ├── success_page.py  # Страница успешного оформления
│
│── tests/               # Тесты
│   ├── test_order.py    # Тестирование процесса заказа
│   ├── test_faq.py      # Тестирование раздела FAQ
│
│── helpers/             # Вспомогательные функции
│   ├── waiters.py       # Функции ожидания
│   ├── actions.py       # Функции кликов и ввода данных
│
│── data.py              # Тестовые данные
│── locators.py          # Локаторы элементов страниц
│── urls.py              # URL-адреса страниц
│── conftest.py          # Фикстуры для pytest
│── requirements.txt     # Зависимости проекта
│── README.md            # Описание проекта
```

## Установка и запуск
### 1. Установка зависимостей
Перед запуском тестов необходимо установить зависимости:
```bash
pip install -r requirements.txt
```

### 2. Запуск тестов
Запуск всех тестов:
```bash
pytest --alluredir=allure-results
```

Генерация отчета:
```bash
allure serve allure-results
```

### 3. Настройка драйвера браузера
Для работы `selenium` требуется установленный WebDriver (GeckoDriver).


## Описание тестов
### Тесты оформления заказа (`tests/test_order.py`)
Проверяются следующие сценарии:
- Оформление заказа с разными наборами данных и точками входа
- Редирект по логотипу Самоката на главную страницу
- Редирект по логотипу Яндекса на страницу Дзена

### Тесты раздела FAQ (`tests/test_faq.py`)
Проверяются:
- Корректность отображаемых ответов при клике на вопросы FAQ
